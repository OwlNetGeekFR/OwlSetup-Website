TRANSPARENCE ET CONTRÔLE

Vos données restent
sur votre PC.

OwlSetup est conçu comme un outil local. Il affiche ce qu’il va faire, demande une confirmation pour les opérations sensibles et ne requiert aucun compte.

✓ Aucun compte✓ Open source✓ Télémétrie facultative✓ Historique local

Les protections essentielles

⌂

Données locales

Préférences, notifications et rapports restent dans le profil Windows de l’utilisateur.

✓

Confirmation avant action

Nettoyages et désinstallations passent par un aperçu. L’UAC apparaît seulement quand Windows exige une élévation.

↶

Restauration facultative

La création automatique d’un point de restauration est proposée, jamais imposée, et dépend de la protection système Windows.

♢

Documents protégés

Documents, images, musique et vidéos ne font pas partie des suppressions automatiques.

◎

Sources officielles

WinGet et les pages des éditeurs servent de référence. Les résultats externes restent signalés avant ajout.

</>

Code consultable

Le dépôt public permet d’examiner le code, les changements et les rapports de sécurité.

Télémétrie : uniquement avec votre accord

L’envoi automatique minimal peut être refusé dans les paramètres. Les diagnostics transmis excluent le nom, l’e-mail, les chemins personnels, la liste des logiciels et le contenu des journaux.

Peut être envoyé

  • Version d’OwlSetup et langue
  • Catégorie et code technique de l’échec
  • Étape concernée et empreinte anonyme

N’est pas envoyé

  • Identité et adresse IP enregistrée
  • Documents, mots de passe ou historique navigateur
  • Journal complet ou liste des applications

SHA-256 et signature numérique

L’exécutable stable n’est actuellement pas signé. Le SHA-256 confirme que le fichier correspond à celui publié, mais ne remplace pas une signature d’éditeur. Téléchargez toujours depuis la Release GitHub officielle.
